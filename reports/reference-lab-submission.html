5. Validate observable behavior

The student ran mvn spring-boot:run and shared H2 and Swagger screenshots. The H2 view showed five book rows. Swagger showed GET /books/1 returning 200 and an unknown ID returning 404 with Book not found. Codex then explained the controller-to-database request flow.
